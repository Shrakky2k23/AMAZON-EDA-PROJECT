Amazon EDA Project
Objective

Performed Exploratory Data Analysis (EDA) on an Amazon product dataset using Python to extract meaningful business insights related to pricing, ratings, and product categories.

Tools & Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook / Google Colab
Analysis Performed
Data Cleaning
Handling Missing Values
Removing Duplicate Records
Product Rating Analysis
Price Analysis
Category-wise Analysis
Data Visualization using Graphs and Heatmaps
Key Insights
Electronics category contained the highest number of products.
Most product ratings ranged between 4.0 and 4.5.
Expensive products were not always highest rated.
Certain categories dominated Amazon listings.
